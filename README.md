Welcome to the **Elite Edition** of my professional portfolio. This project represents a comprehensive UI/UX overhaul, transitioning a standard personal site into a "God Tier" digital experience with high-fidelity animations, premium aesthetics, and modern performance optimizations.

---

## ✨ Premium Features

### 🎨 Visual Excellence
- **Hero Spotlight Background**: An interactive radial spotlight effect that follows the cursor, adding depth and focus to the landing experience.
- **Glassmorphism Design**: High-end frosted glass effects applied to cards and navigation, providing a sleek, modern aesthetic.
- **Dark & Light Mode**: A seamless, state-persisting theme engine with smooth transitions.
- **Custom Cursor Engine**: A reactive dual-dot cursor that interacts with links and interactive elements.

### 🎬 Immersive Motion
- **GSAP & ScrollTrigger**: Precision-engineered scroll animations for every section, creating a dynamic storytelling flow.
- **Lenis Smooth Scroll**: Silky-smooth inertial scrolling for a premium browsing feel.
- **3D Interactive Cards**: Projects are showcased using advanced 3D flip cards (built with CSS `preserve-3d`) that reveal details on click/hover.
- **Bi-Directional Reveal**: Elements gracefully slide and fade into view as they enter the viewport, with "out-of-view" resets for continuous engagement.

### 🛠️ Technical Prowess
- **Responsive Architecture**: Fully optimized for every device, from ultra-wide monitors to mobile screens.
- **Performance Optimized**: Lazy-loaded assets and lightweight script executions for near-instant page loads.
- **Interactive Form Engine**: A polished contact system with real-time feedback and success overlays.
